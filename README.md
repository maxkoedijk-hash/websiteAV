# Aiconic Voices website

Statische website (HTML/CSS/JS, geen build-stap). Open `index.html` in de browser.

- `index.html`: homepage met stemmen, werkwijze, team, FAQ (met FAQPage-schema) en contact
- `assets/css/style.css`: stijl (kleuren en typografie staan bovenaan als variabelen)
- `assets/js/main.js`: mobiel menu, audiofragmenten, contactformulier
- `assets/img/`: tijdelijke uitsnedes van de huidige site; vervangen door originele foto's in hoge resolutie

Audiofragmenten: zet het pad naar een mp3 in `data-sample` op de afspeelknop van een stem.
